# 前后端通讯协议（骨架）

> 状态：骨架，待细化。类似 GraphQL 但自研、轻量。

## 1. 设计目标

- 轻量：低于 GraphQL 的复杂度，满足 Trellis 数据需求声明
- 数据地图驱动：前端声明需求，后端递归查询复杂字段聚合清洗
- 与 Model/function 体系对齐：协议基于 Model 定义推导

## 2. 核心概念

- **数据地图（data map）**：前端声明的查询需求（类 GraphQL 选择集），可嵌套复杂字段
- **请求/响应**：function 调用（后端执行）+ 数据查询
- **递归查询**：后端按 Model 关系图递归装配数据

## 3. 待细化项

- 数据地图语法（字段选择、嵌套、参数）
- 请求/响应格式（序列化、错误语义）
- 批处理 / 缓存 / 订阅（阶段 5）
- 类型系统映射（逻辑类型 ↔ 协议类型）

## 4. 边界

- 只做 Trellis 需要的，不做通用 GraphQL 全集
- 协议演进要向后兼容（版本化）
