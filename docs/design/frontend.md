# 前端设计（骨架）

> 状态：骨架，待细化。技术栈：React（适配层第一目标）。基于 `concepts.md` 前端核心概念。

## 1. ViewModel / XML

- ViewModel 结构：XML 描述布局/组件（0 代码）
- XML schema：非展示容器（绑定 Model/Field）+ 展示组件（从父节点取数据）
- property 绑定：组件事件 ↔ Model function
- **待细化**：XML 语法设计、绑定表达式语法、命名空间

## 2. 无头组件体系

- 无头组件两层：
  - 逻辑层：数据拉取、状态、行为（跨组件库通用）
  - 适配层：注入到具体三方组件库（React 优先）
- 组件类型 Model 化 + 命名空间 + 版本对应
- **待细化**：逻辑层契约、适配层接口、组件注册表

## 3. 前端 function 执行

- 前端执行：function 直接在前端运行逻辑
- 后端执行：封装为请求
- 前端执行引擎（解释编排图或直接执行）
- **待细化**：前端执行引擎、与后端编排图的复用关系

## 4. 通讯（数据地图）

- 前端数据地图声明 → 协议请求 → 后端递归查询聚合返回
- **待细化**：数据地图格式、结果缓存、更新策略

## 5. 管理面（自举，阶段 6）

- 管理面本身是 View（用 View/XML 构建）
- 元数据 CRUD：Model/Field/Function/View
- 初期 XML/JSON 编辑 → 可视化编辑
- **待细化**：管理面 View 集、编辑器实现
