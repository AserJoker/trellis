## 架构总览（骨架）

```
┌─────────────────────────────────────────────────┐
│                   管理面（自举）                  │
│   View 管理 View / Model 管理 Model             │
│   初期 XML/JSON 编辑 → 后期可视化编辑            │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│                   前端运行时                     │
│  ViewModel(XML) → 无头组件逻辑层 → React 适配层  │
│  数据地图查询 / 前端 function 执行               │
└──────────────────────┬──────────────────────────┘
                       │ 协议（类 GraphQL 自研轻量）
┌──────────────────────▼──────────────────────────┐
│                   后端运行时                     │
│  Model 注册表 → 查询聚合引擎（递归复杂字段）      │
│  function 编排引擎（原子操作组合）                │
└──────────────────────┬──────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────┐
│                   存储层                        │
│  阶段一：JSON 序列化落盘（受限环境临时方案）      │
│  后续：抽象存储接口 + 数据库适配器               │
└─────────────────────────────────────────────────┘
```

## 分层边界（骨架）

1. **元数据层**：Model/Field/Function/Type 的定义与注册（元数据本身可被管理面 CRUD）。
2. **存储层**：阶段一 JSON 落盘，接口抽象后置；管理面元数据量小，JSON 可接受。
3. **后端运行时**：查询聚合引擎（递归复杂字段 + 清洗）+ function 编排引擎（原子操作组合）。
4. **协议层**：类 GraphQL 自研轻量协议（前端数据地图 → 后端递归查询）。
5. **前端运行时**：ViewModel/XML 解析 → 无头组件逻辑层 → React 适配层渲染；前端 function 执行。
6. **管理面**：用 View 管理 View/Model（初期 XML/JSON 编辑，后期可视化）。

## 关键横切机制（骨架）

- **自举**：ModelModel 描述 Model，FieldModel 描述 Field，FunctionModel 描述 Function，TypeModel 描述 Type，组件类型 Model 描述组件。
- **命名空间 + 版本**：组件/模块通过命名空间+版本保证元数据与实现对应。
- **模块化**：热拔插模块（设计暂缓，概念提及）。
